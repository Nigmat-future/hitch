# Security

hitch handles API keys for the tools on your machine. If you find a way for
it to leak a key, write outside the files listed in `PRIVACY.md`, or accept a
request on the panel from another origin, please report it privately.

* Open a [private security advisory](https://github.com/Nigmat-future/hitch/security/advisories/new)
  on GitHub, or
* email the maintainer address on the GitHub profile.

Please include the hitch version (`hitch --version`), Node version, platform,
and a minimal reproduction. Do not include real keys in the report.

Supported: the latest release on the `main` branch.
